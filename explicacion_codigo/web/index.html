02 / Bloque inicial · Módulo e imports

Qué define y qué importa el módulo.

El encabezado establece los nombres disponibles.

module AIMoneyLoop where

import Data.Map (Map)
import qualified Data.Map as Map
import Data.List (foldl')
  • module: nombre del módulo; sin lista de exportación, expone sus definiciones.
  • Map: nombre del tipo. Map.fromList: operación con prefijo para identificar su origen.
  • foldl': plegado que aplicará la transición repetidamente.

NamedFieldPuns está habilitado, pero no se utiliza en el código actual.

03 / 1. Tipos de datos · Constructores y registros

Definir valores y acceder a sus campos.

data crea un tipo; sus constructores crean valores.

data Confianza = Alta | Baja deriving (Show, Eq)

-- Campo de DatosFinancieros:
demandaComprometida :: Maybe (Double, Confianza)

-- Uso de un accesor:
ingresosTotales datos
  • Alta | Baja: dos alternativas del tipo Confianza.
  • Show permite mostrar; Eq, comparar.
  • Un registro genera accesores: ingresosTotales datos obtiene un campo.
04 / 1. Tipos de datos · Maybe y GrafoAI

type GrafoAI = Map String

05 / 2. Modelo sin red · Guardas y firma

Tres argumentos. Un resultado.

:: introduce el tipo de la función.

impactoSinRed :: String -> Double -> String -> Double
impactoSinRed origen shock nodo
  | nodo == origen = shock
  | otherwise      = 0.0
  • Los argumentos son origen, shock y nodo; el último Double es el resultado.
  • Las guardas | prueban condiciones en orden.
  • otherwise equivale a True: cubre el caso restante.
06 / 3. Pesos fijos · calcularRij

Nombrar cálculos con let / in.

Los accesores extraen datos; los nombres locales organizan el cálculo.

let ratioC = safeDiv (volumenVentas relacion) (ingresosTotales origen)
    ratioA = safeDiv (accionesPoder relacion) (capMercado destino)
    ratioF = safeDiv (colateralGpu relacion) (deudaTotal destino)
    resultado = (wc * ratioC + wa * ratioA + wf * ratioF) * 100
in clamp 0.0 100.0 resultado

wc = 0.50, wa = 0.30 y wf = 0.20. No se modifica ninguno de los registros recibidos.

07 / 3. Pesos fijos · safeDiv y clamp

Elegir patrones y componer funciones.

Las ecuaciones de safeDiv se prueban de arriba hacia abajo.

safeDiv _ 0 = 0
safeDiv x y = x / y

clamp lo hi x = max lo (min hi x)
  • Si el segundo argumento es 0, devuelve 0; _ ignora el primero.
  • En otro caso, los nombres x e y reciben los argumentos.
  • min hi x limita por arriba; max lo limita por abajo.
08 / 3. Pesos fijos · generarMatrizFija

Desarmar tuplas y recorrer listas.

Una comprensión construye una arista ponderada por cada conexión.

[ (origen, destino, calcularRij datosOrigen datosDestino relacion)
| (origen, (datosOrigen, conexiones)) <- Map.toList grafo
, (destino, relacion) <- conexiones
, let datosDestino = fst (Map.findWithDefault (datosVacios, []) destino grafo)
]

fst toma el primer elemento de la tupla. El valor por defecto evita una búsqueda fallida, pero no agrega el destino al grafo. MatrizRelaciones es una lista de tuplas, no un arreglo 2D.

09 / 4. Propagación · pasoPropagacion

Filtrar entradas, sumar y construir un Map.

EstadoImpacto es un alias de Map String Double.

impactoRecibido nodo =
  sum [ (Map.findWithDefault 0 origen estadoActual) * (peso / 100)
      | (origen, destino, peso) <- pesos
      , destino == nodo
      ]
-- Resultado de pasoPropagacion:
Map.fromList [ (n, Map.findWithDefault 0 n estadoActual + impactoRecibido n)
             | n <- nodos ]
  • destino == nodo filtra las aristas entrantes; sum reúne sus aportes.
  • nodos = Map.keys grafo fija las claves del nuevo estado. Map.fromList construye un mapa nuevo.
10 / 4. Propagación · Estado anterior y estado nuevo

Todas las lecturas usan el mismo estado.

Un ejemplo mínimo: A → B → C, con pesos del 10 %.

No se actualizan nodos uno por uno sobre el mismo mapa. La salida completa es un valor nuevo; el estado anterior se conserva.

Ejemplo didáctico simplificado, distinto del dataset de diez empresas.

11 / 4. Propagación · propagarShock y foldl'

Repetir una transición con un acumulador.

La función anónima transforma el estado; el número del paso se ignora.

let estadoInicial = Map.insert origen shockInicial
                      (Map.fromList [ (n, 0) | n <- Map.keys grafo ])
in foldl' (\est _ -> pasoPropagacion grafo pesos est) estadoInicial [1 .. pasos]

\est _ -> ... recibe el acumulador e ignora el elemento de [1..pasos]. Con cero pasos devuelve el estado inicial.

La prima fuerza cada acumulador a su forma externa; no evalúa profundamente todo el Map. La función devuelve solo el estado final, sin historial.

13 / 5. Atención · Reutilizar una función

Una función también es un valor.

La asignación conserva la misma firma y comportamiento.

coeficienteAtencion :: DatosFinancieros -> DatosFinancieros
                    -> RelacionCruzada -> Double
coeficienteAtencion = calcularRij

La propagación recibe pesos como parámetro, por eso no depende de cómo se obtuvieron.

Es un placeholder y main no lo invoca. Una futura matriz de atención debe respetar la escala porcentual esperada por la transición.

14 / 6. Estudio de eventos · Registros y funciones pequeñas

Valores configurados y funciones disponibles.

Definir una función no significa ejecutarla desde main.

eventoShockHBM = DatosEvento
  { fechaEvento = "2026-02-02"
  , diasEstimacion = 120
  -- otros campos en el código fuente
  }

retornoAnormal observado beta indice =
  observado - (beta * indice)

retornoAnormalAcumulado = sum
  • El registro se construye indicando nombres de campos; el fragmento omite algunos.
  • La resta recibe tres números: no estima beta ni incluye alfa.
  • retornoAnormalAcumulado = sum equivale a recibir una lista y sumarla.

En el fragmento se abreviaron los nombres de los argumentos de retornoAnormal. main imprime el evento; no llama a las funciones de retornos.

16 / 8. main · Cálculos puros y efectos

do ordena las acciones de salida.

IO () representa una acción con efectos que devuelve la unidad ().

main :: IO ()
main = do
  let ecosistema = obtenerEcosistema
      matrizFija = generarMatrizFija ecosistema
      impactoFinalFijo = propagarShock ecosistema matrizFija "SK_Hynix" 100.0 5
  -- luego: putStrLn, print y mapM_

El let dentro de do no lleva in. Por evaluación perezosa, definir estos nombres no obliga a calcularlos inmediatamente.

17 / 8. main · mapM_, lambdas y roundTo

Imprimir una lista mediante acciones.

Cada tupla se desarma, se formatea y se imprime.

mapM_ (\(o, d, p) ->
  putStrLn (o ++ " -> " ++ d ++ " = " ++ show (roundTo 2 p) ++ "%"))
  matrizFija

mapM_ print (Map.toList impactoFinalFijo)
  • \(o, d, p) -> es una función anónima cuyo patrón separa la tupla.
  • ++ concatena textos; show convierte un valor a texto.
  • mapM_ ejecuta las acciones en orden y descarta sus resultados.

roundTo: multiplicar por 10ⁿ → round → fromInteger → dividir por 10ⁿ. Se usa al mostrar los pesos; la propagación conserva sus valores originales.
